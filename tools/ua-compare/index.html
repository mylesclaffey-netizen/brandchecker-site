User-agent comparison

Fetches a page twice with two different user agents and diffs what each one actually gets back — status, title, canonical, noindex, H1, structured data, and content length.

Compares Googlebot against an identical browser with the Googlebot signature stripped — isolates whether the site treats Googlebot differently, not an unrelated browser difference.

Reads the page twice, once per user agent — nothing changed on your site.
