KPI Monitor

The handful of numbers that matter, checked every day against the targets you set. You get a weekly or monthly summary by email, and an alert when a number leaves its expected range or slips off its target. Numbers come from Search Console, your rank and AI-answer trackers, the results of other tools you have run (PageSpeed, backlinks, schema, sitemap, local grid), a PageSpeed check we run every week, or figures you type in.

Search clicks and impressions use the last 28 days against the 28 before. Rank and AI-answer figures compare the latest run with the one before. A target path runs in a straight line from where a KPI stood when you set it to the target date: on track is within 10% of that line, at risk within 35%. Figures from your saved tool runs update whenever you run that tool again; the weekly PageSpeed check runs on its own. The expected range for Search Console counts comes from the prior eight weeks and last year's seasonal shape.
