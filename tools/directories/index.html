Directory listings

Load your list of directories once (upload a CSV). For each location of a client, the tool looks for its listing on every directory, checks that the name, address and phone match, and turns the directories it is missing from into a work list: open one, copy the correct details, submit.

Columns it understands: Directory Name and URL (required), Category, Cost / Access Model, Best For / Notes and an optional Submit URL (the page where a listing is added) and Country (Canada, US or Any: a directory is only checked for locations in its country; with no Country, a .ca address or "Canada" in the name means Canada, anything else serves every country). Other columns are ignored.

2. The client's locations

Each location is checked on its own against its own details, so they must be exactly how that location should appear. A client with several locations is matched more strictly: a listing only counts for a location when it shows that location's phone, street or postal code.

CSV columns: Name, Address, City, Postal, Phone (plus optional Label, Website, Country). A row for an address already listed updates it. The copy from the Business Profile manager is read-only and can be run again: it only adds locations that are new there.

3. Check the directories

One Google search per directory, about $0.002 each, then the listing page is read for its details. Directories that refuse automated readers are marked "check by hand" rather than guessed. A doctor's own page (on RateMDs or Healthgrades, say) is not the clinic's listing: it is shown beside the row but the clinic still counts as missing. Search can miss a listing that exists, so "not found" is worth a quick look before submitting.

4. Re-check on a schedule

Re-checks the directories already checked, for every location, and emails you only when something changed: a listing that has disappeared, details that now differ, a new listing found, an update that is now confirmed, or a submitted listing that is now live. A failed search never counts as a change, and a listing is only reported gone after two misses in a row.
