Business Profile manager

All your clients' Google Business Profiles in one workspace. Each analysis compares a profile with the businesses Google Maps shows for its main search: their categories, reviews and photos. It checks the client's website says the same as the profile, reads the latest reviews, and keeps a list of the changes to make. The next analysis confirms each change once Google shows it.

You make the changes in Google's own dashboard for now: each one comes with the text to paste and where the setting is. Sending changes straight to Google needs Google to approve API access, and comes later.
